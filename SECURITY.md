# Security Policy

## Supported versions

Security fixes are provided for the latest major release.

| Version | Supported |
|---|:---:|
| 3.x | Yes |
| 2.x and earlier | No |

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email
`dleliuhin@mail.ru` with a description, reproduction steps, affected
versions, and potential impact. Avoid including sensitive data.

You should receive an acknowledgement within seven days. The maintainer will
coordinate validation, remediation, and disclosure with the reporter.
